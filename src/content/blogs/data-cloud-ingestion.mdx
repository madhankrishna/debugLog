Data projects become much easier when you understand where data originates, how it is transformed and how identity is handled.

## Map the source first

Document the source system, ownership, refresh expectations and important fields.

## Think about identity early

Identity resolution can affect the usefulness of downstream segmentation and activation.

## Validate before scaling

Start with a small representative dataset and verify the model before increasing volume.
