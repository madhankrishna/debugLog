Pricing becomes easier to reason about when product configuration, pricing logic and transaction context are kept separate.

## Start with the business rule

Before implementing a pricing rule, describe the expected outcome in plain language.

## Keep configuration understandable

A good implementation should make it clear which parts are configuration and which parts require custom code.

## Test the edge cases

Always test discounts, quantities, currencies and unusual combinations before production rollout.
